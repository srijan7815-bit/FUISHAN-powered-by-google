# Contributing to FUISHAN

First off, thank you for considering contributing to FUISHAN! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## How to Contribute

1. **Fork the repo** and create your branch from `main`.
2. **Clone** your fork locally.
3. If you've added code that should be tested, add tests.
4. If you've changed APIs, update the documentation.
5. Ensure your code passes all linting and type checks (`npm run lint` & `npm run build`).
6. Issue that pull request!

## The Vibe Code of Conduct
- Be respectful and collaborative. 
- Keep the code modular and lean. We prioritize speed and aesthetic.
- Do not submit PRs that break the core "Zero-Setup Vibe Coding" philosophy. The tool must remain accessible to non-coders.

## Found a Bug?
If you find a bug in the source code, you can help us by [submitting an issue](#) to our GitHub Repository. Even better, you can submit a Pull Request with a fix!
